# Egress allowlist for the dev container.
#
# init-firewall.sh resolves every name below to its A records at container
# start and puts those addresses in an ipset; everything else outbound is
# dropped. Blank lines and `#` comments are ignored. GitHub is NOT listed here:
# its address ranges are pulled from https://api.github.com/meta instead,
# because they are many and they move.
#
# Two things to know before editing:
#
#   * This file is baked into the image. Edit it, then "Dev Containers: Rebuild
#     Container" — a running container keeps the list it started with. That is
#     deliberate: an allowlist the agent could widen in place would not be one.
#
#   * Names are pinned to the IPs they resolved to at start time. Big CDNs
#     rotate addresses, so a long-lived container can start seeing failures
#     that a re-run of `sudo /usr/local/bin/init-firewall.sh` fixes.

# --- Distro packages -------------------------------------------------------
# apt inside a running container is a poor habit — the reproducible fix is to
# add the package to the Dockerfile — but a blocked `apt-get update` produces a
# baffling error, so the mirrors are open. These are round-robin CDNs and are
# the entries most likely to need a firewall re-run.
